# ex2.2-user-login-registration
Bài tập 2.2 yêu cầu xây dựng ứng dụng Windows Forms gồm 3 form (Đăng nhập, Đăng ký, Chính) kết nối trực tiếp với SQL Server. Hệ thống thực hiện băm mật khẩu bằng PBKDF2 với Salt ngẫu nhiên, dùng câu lệnh SQL có tham số để chống SQL Injection và hiển thị thông báo lỗi .
